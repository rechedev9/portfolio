# luisreche.dev

Portfolio for **Luis Reche** — Applied AI Engineer.

One minimal page in the josepvidal.dev style: `/me`, `/always`, `/highlights`, `/projects` and `/live`, with light and dark mode. Content lives in `src/data/portfolio.ts`.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- React Router

## Commands

```bash
npm install
npm run dev
npm run build
npm run typecheck
npm run lint
```

- CV: `public/Luis-Reche-Applied-AI-Engineer-CV.pdf` (same file also at `public/luis-reche-cv.pdf` so older links keep working)
